# SEO Compass

メインキーワードと関連キーワードを軸に、目標設定・順位履歴・競合比較・改善作業を管理する日本語Webアプリです。参考画像の白とインディゴのダッシュボードを、PC・スマートフォン向けに実装しています。

## 起動

Node.js 22以上を推奨します。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173/ を開きます。製品ビルドは `npm run build`、ビルド確認は `npm run preview`、ロジックのテストは `npm test` です。

## 実装済み機能

- 複数プロジェクトの作成・切替・削除
- メインキーワード、地域、端末、目標順位、期限の設定
- 関連キーワード登録・検索・削除
- 日別順位の手動記録、同日上書き、圏外と未計測の区別
- 28日・90日・1年の順位グラフ
- 競合ページ登録と3領域の手動評価、自社と競合中央値の比較
- 根拠・対象URL・工数・優先度・作業チェックリスト付き改善チケット
- 未着手 → 対応中 → 効果検証中 → 完了の状態管理
- チェック項目が未完了なら検証中・完了への変更をブロック
- ブラウザ内自動保存、JSONバックアップ・検証付き復元、順位履歴のCSV出力
- キーボード操作対応ダイアログ、スマートフォンの下部ナビゲーション

初回は「サンプルデータ」のプロジェクトを表示します。「自分のサイトを登録」でサンプルの混ざらないプロジェクトを作れます。自社ページのメインキーワードを変更した場合、そのキーワードの履歴をリセットします。

## データと制約

この版は **手動記録型のMVP** です。自動クロール、Google Search Console / GA4 / SERP API、AIによる診断や改善案生成、認証、共有DB、端末間同期は未実装です。URLを登録しても検索順位や競合情報を自動取得しません。APIキーや課金は不要です。

データは `seo-compass-v1` というキーでブラウザのlocalStorageに保存します。サーバーへ送信しません。利用するブラウザ・URL（オリジン）ごとに保存領域が分かれます。ブラウザのデータ削除で失われるため、設定からバックアップしてください。複数タブでの同時編集には対応していません。

競合スコアは作業整理のための独自評価であり、Googleの評価値でも検索順位の予測でもありません。空欄は0点とせず中央値から除外します。順位の観測条件はプロジェクトごとに固定します。Search Consoleの平均順位は将来連携時も別指標として扱います。

## 構成

- React / TypeScript / Vite / Lucide
- `src/model.ts`: バージョン付き保存形式、型、集計、サンプル、バックアップ検証
- `src/App.tsx`: 5画面と入力・管理フロー
- `src/style.css`: レスポンシブUI
- `.openai/hosting.json`: Sitesの静的配信設定

## 受入確認

1. 新規プロジェクトの順位が「未計測」、競合評価が「未評価」になる。
2. 順位を記録すると概要カードとグラフへ反映され、再読み込みしても保持される。
3. 同日の再記録は上書きされ、圏外は順位0として表示しない。
4. 全チェック未完了のチケットは効果検証中・完了にできない。
5. 競合評価は登録済みの値のみで中央値を計算する。
6. バックアップを出力して復元でき、不正なスキーマのJSONは拒否する。
7. 390pxの画面幅とデスクトップで主要操作を利用できる。

## 次期実装

本番の自動分析には、認証・テナント分離のあるDB、Google OAuth、ジョブワーカー、適法に利用できるSERPデータ提供契約が必要です。サーバー側の導入時に、プロジェクト・キーワード・観測・分析根拠・チケットを別テーブルに移し、取得時刻とソースを保持します。外部URL収集にはSSRF対策とアクセス制限を実装します。現在の画面に自動取得済みのような表示を追加しないでください。
